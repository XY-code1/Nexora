# Local Review UI

本地审核界面用于完成候选记忆的修改、确认和拒绝，不向MCP Agent开放高风险写入权限。

## Windows启动

双击：

```text
start-review.vbs
```

它会在后台启动仅监听`127.0.0.1`的服务并打开浏览器。默认私人Vault位于框架目录旁的`my-ai-profile`；也可以通过本机环境变量`PROFILE_VAULT`指定。

如果界面没有打开，双击`start-review.cmd`查看错误信息。

审核结束后点击页面底部的“关闭审核界面”，后台本地服务会一并停止。

## 安全边界

- 仅绑定`127.0.0.1`，不监听局域网或公网；
- 拒绝非localhost的Host请求；
- 所有状态修改使用随机CSRF令牌；
- 请求体和输入长度有限制；
- 文件名继续经过Vault目录约束；
- 设置`no-store`、CSP、`nosniff`和禁止外部引用；
- UI不提供物理删除、公开发布或修改Profile能力。

## 当前操作

```text
查看候选列表
查看来源Agent和状态
修改候选内容
确认长期记忆
拒绝并记录原因
```
