# Human 3.0 对话式复盘生命周期

Human 3.0是可选的本地自我反思工具，不是医学、心理或能力诊断。系统不根据活动数据推断情绪、动机或发展等级。

## 闭环

```text
用户明确开始复盘
→ 依次填写Mind、Body、Spirit、Vocation
→ 每个维度记录反思、可观察依据、信息充分度和0–10自评分
→ 用户填写摘要和未来30天行动计划
→ 保存本地Markdown草稿
→ 用户明确确认
→ 草稿原子移动到History
→ 本地趋势页和获得assessment:read权限的MCP只读取显式摘要
```

## 边界

- 同一时间最多有一个进行中的草稿。
- 若`Answers`中存在旧版问卷草稿，新版复盘会拒绝启动，避免覆盖；用户可先在Obsidian中处理旧草稿。
- 草稿保存在`40 Reviews/Human3/Answers`，不会进入趋势或MCP结果。
- 正式记录只由本地认证界面的用户确认，MCP没有确认能力。
- 所有写操作使用Vault文件锁、revision校验和秘密扫描。
- `limited`与`insufficient`是有效信息状态，不能为追求完整而自动补全依据。
- 分数是用户自评，不由系统计算。
- 确认操作使用事务日志，避免移动过程中留下半完成状态。
