# 对话式首次引导与渐进信息收集

Phase 8采用本地、确定性的渐进式问答，不连接模型或云端服务。引导覆盖称呼、沟通方式、长期目标、当前关注和隐私边界五个主题。

## 数据边界

- 页面按顺序一次只提出一个问题，用户可以随时跳过。
- 不保存完整聊天过程、跳过记录或输入中的临时草稿。
- 只有用户点击“保存为候选并继续”并明确提交后，才创建一条candidate。
- candidate仍需在记忆审核页面由用户确认；引导不能直接修改Profile或创建确认记忆。
- 输入继续经过长度校验和秘密扫描，密码、Token、API Key等内容会被拒绝。
- API、MCP和其他AI的读取权限没有扩大。

## 主题状态

```text
available  尚未回答，可以继续引导
pending    已生成候选，等待用户审核
confirmed  已确认，或Profile中已有对应结构化信息
```

被拒绝、遗忘或仅本轮跳过的主题以后仍可重新回答。
