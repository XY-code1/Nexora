# NEXORA Product Identity

Version B2/B3 · 2026-11-09

## Naming hierarchy

| Layer | Approved name | Usage |
|---|---|---|
| Brand | **NEXORA** | primary global product and project name |
| Chinese name | **知序** | paired Chinese identity; not a translation subtitle |
| Category | **Personal Intelligence Platform** | product category and descriptive label |
| Tagline | **Your Intelligence. Your Data. Your Control.** | public promise and first-run brand statement |
| Legacy project name | Personal AI Profile | compatibility/history only; not the primary UI identity |

Use “NEXORA（知序）” on first mention in bilingual material. Use “NEXORA” afterward. Do not rename the GitHub repository, Python modules, environment variables, Vault schemas or API identifiers as part of the brand migration.

## Product promise

NEXORA connects personal memory, identity, knowledge and AI tools while keeping the user in control of data, permissions and what becomes durable memory.

## B2 — Product identity application

- Browser title and metadata use NEXORA（知序）.
- The workspace lockup uses the Intelligence Core symbol, NEXORA and 知序.
- First-run onboarding introduces the brand and official tagline.
- User-facing sample import content uses the current product identity.
- Technical compatibility identifiers remain unchanged.

## B3 — Public identity application

- README leads with the official logo, category and tagline.
- English remains the primary open-source narrative with a first-class Chinese overview.
- Brand documentation is linked from the main documentation index.
- Public links use the repository current canonical URL; changing repository settings remains outside this phase.
- Preview assets remain outside application navigation and business routes.

## Migration boundaries

This phase does not:

- rename the GitHub repository;
- rename package names, API routes, environment variables or Vault directories;
- modify Core, MCP, permissions, data lifecycle or storage behavior;
- restyle product pages beyond replacing the workspace brand lockup;
- load remote fonts or images.

Future identity migrations must be versioned separately from data/schema migrations.
